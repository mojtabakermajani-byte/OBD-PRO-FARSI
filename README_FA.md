# OBD PRO فارسی — Android source

این بسته یک پروژه منبع Android برای OBD-II از طریق ELM327 Bluetooth Classic (SPP) است.

## ساخت APK
- پروژه را در ریشه یک مخزن GitHub بارگذاری کنید.
- پوشه `.github` را نیز بارگذاری کنید.
- از Actions، گردش کار Build OBD PRO APK را اجرا کنید.
- خروجی `OBD-PRO-debug-APK` را دریافت کنید.

## محدودیت‌های فنی مهم
- این برنامه برای PIDهای استاندارد OBD-II و ماژول موتور طراحی شده است.
- نمایش هر PID وابسته به پشتیبانی ECU خودرو است؛ مقدار ساختگی جایگزین داده واقعی نمی‌شود.
- خواندن/پاک کردن DTC استاندارد موتور پیاده‌سازی شده است.
- ABS، ایربگ، گیربکس، تست عملگرها و کدهای اختصاصی سازنده در این نسخه ادعا یا شبیه‌سازی نشده‌اند؛ برای آن‌ها پروتکل/دسترسی اختصاصی و سخت‌افزار سازگار لازم است.
- `ATRV` ولتاژ خود آداپتور را می‌دهد، نه الزاماً ولتاژ ECU/باتری؛ در این نسخه کارت ولتاژ فقط از PID 0142 پر می‌شود.
- این پروژه در محیط فعلی روی دستگاه واقعی یا با Android SDK ساخته و تست نشده است. قبل از استفاده عملی، build و تست با ELM327 و خودرو لازم است.
